# Little Orbit — benchmark v1

Бенчмарк однопромптового создания небольшой законченной браузерной 3D-игры. Основан на опыте разработки Little Orbit, но не требует воспроизводить её код, стиль или технологии.

## Запуск

1. Создать пустой проект и новую сессию проверяемой модели.
2. Передать только содержимое [prompt.ru.md](prompt.ru.md) как пользовательский запрос. Не передавать код Little Orbit, историю разработки, этот README и примеры решений.
3. Дать модели закончить работу без уточнений и корректирующих сообщений. One-shot здесь означает один исходный запрос; инструменты, итерации, тесты и самостоятельное исправление ошибок разрешены.
4. Запустить результат по инструкции модели и пройти основные сценарии вручную.

Для сравнения версий фиксировать модель, дату, доступные инструменты, лимиты времени/токенов, доступ к сети, устройство и браузер проверки. Условия должны быть одинаковыми. Хранить результат каждого прогона отдельно от исходного проекта.

## Оценка

Не включать эту секцию в запрос модели. Оценивать работающий результат, а не обещания в финальном ответе. Для каждой категории использовать шкалу 0–4:

- **0** — отсутствует или не запускается.
- **1** — фрагментарно, существенные ошибки мешают игре.
- **2** — основной сценарий работает, есть заметные пробелы.
- **3** — требования выполнены и согласованы между собой, небольшие недочёты.
- **4** — цельно, устойчиво и убедительно исполнено.

| Категория | Что проверять |
|---|---|
| Законченность | Простой запуск, понятное начало, отсутствие заглушек и блокирующих ошибок |
| Планета и перемещение | Сферическая поверхность, полюса, камера, прыжок, вода и коллизии |
| Мир и визуал | Цельный стиль, распределённые места, живность, читаемые объекты и окружение |
| Персонажи и нарратив | Отличимые жители, естественные мотивы, развитие диалогов, эмоциональные финалы |
| Истории и взаимодействия | Разнообразные завершённые истории, физические находки, понятные подсказки |
| Небо и атмосфера | День и ночь, освещение, облака внутри атмосферы, естественные переходы |
| Солнечная система | Согласованность карты и неба, разные орбиты, постоянное слежение |
| Интерфейс и сохранения | Журнал, перечитывание, восстановление прогресса и позиции, сенсорное управление |
| Звук | Уместное сопровождение, управление звуком, отсутствие нежелательного автозапуска |
| Производительность и надёжность | Плавность на целевом устройстве, стабильные тени, отладка, проверки |

Итого: до 40 баллов. Итог сопровождать конкретными наблюдениями и перечнем невыполненных требований: один балл не заменяет описание результата. Не награждать за конкретный стек, совпадение названий или копирование исходной игры.

Минимальный маршрут проверки: старт → движение и препятствия → разговор и завершение истории → находка вдали от деревни → журнал → смена суток → оба обзора → слежение за движущейся планетой → перезагрузка → сенсорное управление и отладка. Остальные истории проверять отдельно: один рабочий квест не доказывает завершённость остальных.

## Версионирование

`prompt.ru.md` — самостоятельный запрос, готовый к копированию. Для сравнительных запусков записывать commit SHA его версии. Существенное изменение требований оформлять новой версией бенчмарка, чтобы результаты оставались сопоставимыми.
