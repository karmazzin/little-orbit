# Контент: открытки, живой мир и Ирис

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Закончить три оставшихся пункта контента и предложить дальнейшее наполнение.
**Architecture:** Независимое состояние историй с проверяемыми переходами; UI подключается к существующим диалогам и журналу. Животные рисуются инстансами, обновляются 20 Гц, без новых источников света и теней.
**Tech Stack:** TypeScript, Three.js, SVG для иллюстрированных открыток, node:test.
**Spec:** Запрос пользователя «всё, что касается контента»: открытки, небольшие животные, продолжение лагеря и Ириса.

- [x] `src/content.ts`, `tests/content.test.ts`: принять у Миры заказ, зарисовать три места на месте, вернуться с альбомом; отдельное валидируемое сохранение без повторных наград.
- [x] `src/content.ts`, `src/main.ts`: цепочка лагерь → арка и роща → ночной телескоп с видимым Ирисом → расшифровка у Ады. Журнал показывает конкретный следующий шаг. Финал главы даёт запись координат станции для будущего путешествия.
- [x] `src/postcards.ts`, UI: три иллюстрированные открытки с подписями, сбор по P или из осмотра на месте, альбом в журнале.
- [x] `src/wildlife.ts`, `tests/wildlife.test.ts`: бабочки у цветов и в роще, птицы над озером/аркой, три зайца на суше; ограниченные маршруты, реакция на близость, обход воды и коллизий. Инстансы без дополнительных shadow caster.
- [x] `src/main.ts`, `index.html`, `src/style.css`: задания в журнале, дополнительные реплики и кнопки Миры/Ады, подсказки управления. Сохранить прежние письма, открытия, лагерь.
- [x] Все тесты, сборка, независимый обзор кода; README и список будущего контента.
