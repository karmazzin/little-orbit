# Проверка рефакторинга Little Orbit

Исходная точка — рабочее дерево с незакоммиченным Янтарём, сохранённое в `/private/tmp/little-orbit-before-shared-runtime-20260907` (169 файлов, SHA256 manifest, статус Git и binary diff). Сравнение с одним HEAD не отражает исходную функциональность.

## Проверки кода и содержимого

- Исходный набор: 187 тестов, 0 ошибок; production build проходит.
- После выделения runtime: 192 теста, 0 ошибок. Добавлены проверки объединения ввода, сброса команд, времени кадра, фиксированного шага, камеры над водой/рельефом и обзора/слежения.
- 32 перенесённых планетных модуля совпадают с исходниками после нормализации только путей импортов. Исключение — сборка Хвои, из которой отдельно выделены общие персонажи и примитивы.
- Полный отпечаток построенной Хвои: 318 объектов, 244 геометрических объекта, SHA256 `cd6eb980441a475e8aceb07cf3533c5895ababe093e9889ff958ae586e801f7e` — совпадает с исходной копией.
- Полный отпечаток Янтаря: 268 объектов, 228 геометрических объектов, SHA256 `14ff44161ec97843e2201ae31ca018b92e56b1ef6b61b3704558f9050f906cae` — совпадает с исходной копией.
- Отпечатки включают геометрию, атрибуты/индексы, трансформации, основные свойства материалов и instance-матрицы/цвета. Массивы препятствий совпадают отдельно.
- Для мужской модели, Миры и Ады совпали геометрия и позы: покой, сидение, рассказ, приветствие, письма, записи, полив, осмотр, наблюдение и плавание.
- Независимый обзор не выявил игровых регрессий. Замечание о включении сохранения в CPU-замер Хвои устранено и перепроверено; измерение снова начинается после сохранения.

## Браузерные проверки общего кода

`tests/runtime-controls-browser.html`: 27 проверок в headless Chrome. Реальные DOM-события проверяют клавиатуру, подавление ввода в формах, разовые команды, паузу, потерю фокуса, запасной режим мыши, чувствительность, ограничения камеры/масштаба, pinch и замену объекта игрока при сбросе. Только системные API pointer lock/capture подменены в этой изолированной странице.

`tests/runtime-hud-browser.html`: 26 проверок в headless Chrome. Проверены сохранённые различия диалогов Хвои/Янтаря, обновление журнала, закрытие окон и фокус, мобильное меню и ARIA, порядок закрытия перед действием, качество графики и интерфейс плавания.

## Игровые сценарии до и после

Финальный `npm test`: 192/192. Финальный `npm run build`: успешно; сохранилось исходное предупреждение Vite о размере three chunk. `git diff --check`: без ошибок.

`tests/runtime-browser.mjs` воспроизводит шесть сценариев; все шесть прошли на исходной копии и после рефакторинга, без pageerror:

1. Хвоя: запуск, журнал, M/K/N/Escape, движение, сохранение; после перезагрузки игра снова запускается и повторно сохраняется, затем сравниваются положение, время и камера.
2. Янтарь: тот же набор.
3. Переход Хвоя → Янтарь → Хвоя на компьютере.
4. Такой же переход реальными tap-событиями в сенсорной эмуляции.
5. Ошибка записи localStorage блокирует переход с Хвои.
6. Ошибка записи localStorage блокирует переход с Янтаря.

Точность сравнения нормализованных направлений после загрузки — 1e-10; исходная версия также округляет компоненты при нормализации. Прогоны: `/private/tmp/little-orbit-qa/baseline-final/` и `/private/tmp/little-orbit-qa/after-final/`.

Для повторения: запустить `npm run dev`, затем `BASE_URL=http://127.0.0.1:5173/little-orbit/ node tests/runtime-browser.mjs`. Нужны внешний Playwright и Chrome; путь к модулю Playwright можно передать через `PLAYWRIGHT_MODULE`. Зависимости игры не менялись. Изолированные страницы controls/HUD открываются через тот же Vite в `/little-orbit/tests/runtime-controls-browser.html` и `/little-orbit/tests/runtime-hud-browser.html`.

## Границы доказательств

Проверки выполняются в отдельных браузерных контекстах, без изменения пользовательского localStorage. Сохранения подготавливаются как копии/фикстуры старого формата. Отпечаток геометрии не является попиксельным сравнением анимированного изображения. Headless Chrome и эмуляция сенсорного экрана не заменяют проверку на физическом телефоне и целевом GPU.

Полные истории не проходились вручную от начала до конца. Их код перенесён без изменения логики и покрывается существующими предметными тестами. Сам звук на слух и аппаратная производительность не считаются подтверждёнными только по результатам headless-прогона.

Сравнение FPS на целевом устройстве остаётся отдельной проверкой: параллельные headless-прогоны давали слишком большую вариативность для корректного вывода. Ускорение или отсутствие аппаратных просадок по этим прогонам не заявляется. Полный сценарий плавания и сброса не проходился в игровой браузерной сцене; движение/вода/сохранения проверены предметными тестами, HUD плавания — изолированной браузерной проверкой.
