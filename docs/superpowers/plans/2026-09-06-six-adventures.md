# Шесть новых историй

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Реализовать все шесть согласованных идей контента.
**Architecture:** Отдельное валидируемое состояние приключений, каталог интерактивных точек, процедурные модели и UI-адаптер. Старые истории/сохранения и фильтрация теней сохраняются.
**Tech Stack:** TypeScript, Three.js, node:test, Vite.
**Spec:** Последний список из шести предложений, одобренный пользователем.

- [ ] Метеорит: задание Ады → кратер → образец → анализ и награда в журнале.
- [ ] Три бутылки у берегов: отдельные письма складываются в историю; повторное чтение в журнале.
- [ ] Пещера: доступный вход, рисунки первых путешественников и последовательность «солнце → дерево → звезда»; ошибка сбрасывает ввод, решение сохраняется.
- [ ] Колокольчик: просьба Льва → два следа → находка → возврат. При включённом звуке звон рядом, при выключенном — визуальная подсказка.
- [ ] Праздник: после любых двух законченных историй, местным вечером; огоньки, гости, поздравление и отметка участия.
- [ ] Рассказчик: персонаж с повозкой у северного домика; днём через день, три истории о соседних планетах, коллекция в журнале.
- [ ] Интеграция E/J/M, подсказки следующих шагов, совместимые сохранения, маршруты и коллизии.
- [ ] Тесты переходов/восстановления/расписаний/доступности, production-сборка, независимая проверка.

Новые идеи в этой итерации не добавляются. Звук использует существующее согласие на звуки природы. Для быстрого ожидания доступны часы и ускорение времени.
