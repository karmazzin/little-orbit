# Шесть новых историй

> **For agentic workers:** Use superpowers:executing-plans task-by-task.

**Goal:** Реализовать все шесть согласованных идей контента.
**Architecture:** Отдельное валидируемое состояние приключений, каталог интерактивных точек, процедурные модели и UI-адаптер. Старые истории/сохранения и фильтрация теней сохраняются.
**Tech Stack:** TypeScript, Three.js, node:test, Vite.
**Spec:** Последний список из шести предложений, одобренный пользователем.

- [x] Метеорит: задание Ады → кратер → образец → анализ и награда в журнале.
- [x] Три бутылки у берегов: отдельные письма складываются в историю; повторное чтение в журнале.
- [x] Пещера: доступный вход, рисунки первых путешественников и последовательность «Ореол → дерево → звезда»; ошибка сбрасывает ввод, решение сохраняется.
- [x] Колокольчик: просьба Льва → два следа → находка → возврат. При включённом звуке звон рядом, при выключенном — визуальная подсказка.
- [x] Праздник: после любых двух законченных историй, местным вечером; огоньки, гости, поздравление и отметка участия.
- [x] Рассказчик: персонаж с повозкой у северного домика; днём через день, три истории о соседних планетах, коллекция в журнале.
- [x] Интеграция E/J/M, подсказки следующих шагов, совместимые сохранения, маршруты и коллизии.
- [x] Тесты переходов/восстановления/расписаний/доступности, production-сборка, независимая проверка.

Новые идеи в этой итерации не добавляются. Звук использует существующее согласие на звуки природы. Для быстрого ожидания доступны часы и ускорение времени.

Проверка: полный `npm test` — 66/66; `npm run build` — успешно. Независимая проверка выявила несовместимые индексы при объединении геометрии и отсутствие тетради Ноя в счётчике праздника; оба исправлены и покрыты регрессионными тестами. Визуальную оценку пользователь выполняет самостоятельно.

Дополнение по нарративу: переписаны завязка, промежуточные реплики и финал открыток Миры; все шесть историй получили личные мотивы, последовательное раскрытие и сохранённые тексты для повторного чтения.
